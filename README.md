# Разработка веб-сервиса автоматизации приёма заказов и управления кухней ресторана на базе ASP.NET Core и SQLite

Полнофункциональное клиент-серверное веб-приложение (SPA + RESTful Minimal APIs) для автоматизации процесса обслуживания клиентов в зале и диспетчеризации выполнения заказов персоналом кухни ресторана.

---

## 🛠 Стек технологий и архитектура

* **Бэкенд:** C#, платформа .NET 8, ASP.NET Core (Minimal APIs).
* **СУБД:** SQLite (`Microsoft.Data.Sqlite`) с прямыми параметризованными SQL-запросами для защиты от SQL-инъекций.
* **Фронтенд:** Vanilla JavaScript (без сторонних фреймворков), HTML5, адаптивный CSS3 (CSS Grid / Flexbox).
* **Архитектурный подход:** RESTful API, одностраничное веб-приложение (Single Page Application, SPA), автоматическая инициализация схемы БД при старте.

---

## 📋 Основной функционал системы

### 1. Модуль гостя (Электронное меню и оформление заказа):
* Каталог меню с динамической фильтрацией по категориям блюд.
* Интерактивная корзина с операциями добавления, изменения количества и удаления позиций.
* Валидация входных данных (проверка номера столика и непустого состава корзины).
* Расчёт итоговой суммы чека в реальном времени.

### 2. Модуль кухни (Kitchen Display System / KDS):
* Оперативный мониторинг заказов с группировкой по статусам: `Принят`, `Готовится`, `Выдан`.
* Смена жизненного цикла заказа в один клик.
* Панель аналитики текущей смены: счётчики общего числа заказов, блюд в работе и суммарной выручки по выданным заказам.
* Возможность очистки и удаления закрытых чеков.

---

## 🗄 Структура базы данных

Приложение использует реляционную базу данных SQLite с автоматическим созданием таблиц:
* `Orders` — хранение основных данных заказа (`Id`, `TableNumber`, `TotalAmount`, `Status`, `CreatedAt`).
* `OrderItems` — детализация позиций чека (`Id`, `OrderId`, `DishName`, `Price`, `Quantity`).

---

## 🔌 Спецификация REST API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/orders` | Получение списка всех заказов с позициями |
| `POST` | `/api/orders` | Оформление нового заказа из корзины |
| `PATCH` | `/api/orders/{id}/status` | Обновление статуса заказа (`Готовится` / `Выдан`) |
| `DELETE` | `/api/orders/{id}` | Удаление закрытого заказа из базы данных |
